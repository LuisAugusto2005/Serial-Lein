# Comandos importantes:
- 'lein new app cliente'        -> para criar um template no estilo app, como o nome de cliente
- 'lein new compojure server'   -> para criar um template no estilo de servidor, como o nome de server

- 'lein run'                    -> para iniciar Cliente (APP)
- 'lein ring server'            -> para iniciar Server  (Compojure)
